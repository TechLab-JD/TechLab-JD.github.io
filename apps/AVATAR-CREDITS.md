# Steady Character — avatar art credits

The full-body character avatars in Steady Character are built from **Liberated Pixel Cup (LPC)**
sprite art, composited from the **Universal LPC Spritesheet Character Generator**.

- Project: Universal LPC Spritesheet Character Generator — https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator
- Maintained by: Sander Frenken (castelonia) and contributors
- Full per-asset credits: see CREDITS.csv in the project above
